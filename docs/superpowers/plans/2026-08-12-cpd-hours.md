# CPD Hours Tracking (120hr/year) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every staff member accumulates hours toward a fixed 120-hour/calendar-year target from three sources — Video Training (Supervisor-set hours per video), Module Quiz (flat 1hr/attempt), AI Practice (flat 0.25hr/attempt). Staff see their own progress on the Dashboard; Outlet/Area Managers and Supervisor see a per-staff breakdown on their existing Staff Results pages. Real staff/managers see a "Coming Soon" placeholder until the feature is verified; Master-impersonated sessions see the real thing.

**Architecture:** One new column (`video_trainings.hours`, Supervisor-set manually per video) is the only new stored state — hours-this-year is always computed on read. Video Training and Module Quiz attempts share the `results` table (distinguished by whether their `topic` matches a `video_trainings` row — video hours if so, flat 1hr if not); AI Practice attempts live in the separate `ai_results` table, always flat 0.25hr/row. The staff-facing single number is computed server-side (one new field on `GET /data/scoped-data`); the three manager-facing per-staff breakdowns are computed client-side via a shared composable, `useCpdHours.js`.

**Revision note (2026-08-13):** This plan was originally written counting Video Training only. Per `docs/superpowers/specs/2026-08-13-cpd-hours-revision-design.md` (read it first — it has the exact rationale for every decision below), it now also counts Module Quiz and AI Practice, fixes a found gap where Area Manager's `GET /scoped-data` branch returned zero AI Practice data, and adds "Coming Soon" gating. This plan file fully supersedes the original 2026-08-12 version — no tasks from that version were executed, so nothing here preserves now-dead task text.

**Tech Stack:** Same as the Video Training plan this depends on — Node.js/Express/Postgres (backend repo), Vue 3/Vue Router 4/vue-i18n (frontend repo). No new dependencies.

- [ ] **Step 1: Add a shared helper**

In `lautan-academy-backend/src/routes/data.js`, add this near the existing

```js
// CPD hours this calendar year, summed across all three sources:
// - results rows whose topic matches a video_trainings topic: that
//   video's real hours.
// - results rows whose topic does NOT match a video_trainings topic
//   (i.e. Module Quiz): flat 1hr each (coalesce(vt.hours, 1)).
// - ai_results rows (always AI Practice, no topic check needed): flat
//   0.25hr each.
// See docs/superpowers/specs/2026-08-13-cpd-hours-revision-design.md.
async function cpdHoursThisYear(outlet, name) {
  const [videoAndModule, aiPractice] = await Promise.all([
    pool.query(
      `select coalesce(sum(coalesce(vt.hours, 1)), 0) as hours
       from results r
       left join video_trainings vt on vt.topic = r.topic
       where r.outlet = $1 and r.name = $2
         and extract(year from r.created_at) = extract(year from now())`,
      [outlet, name]
    ),
    pool.query(
      `select count(*) * 0.25 as hours
       from ai_results
       where outlet = $1 and name = $2
         and extract(year from created_at) = extract(year from now())`,
      [outlet, name]
    ),
  ]);
  return Number(videoAndModule.rows[0].hours) + Number(aiPractice.rows[0].hours);
}
```

- [ ] **Step 1: Create the composable**

```js
// Pure calculation, no reactive state of its own — every call site already
// owns its own `results`/`aiResults`/`video_trainings` refs from the API
// calls it was already making. Reused identically by the Dashboard and all
// three manager-facing Staff Results pages instead of quadruplicating the
// same join+group logic. See
// docs/superpowers/specs/2026-08-12-cpd-hours-design.md and
// docs/superpowers/specs/2026-08-13-cpd-hours-revision-design.md.

// Flat rates for the two sources with no fixed per-entry hours value to
// attach to (Module Quiz's standard_questions bank has no hours field; AI
// Practice quizzes are generated on the fly per passcode, no catalog at
// all). Video Training's real per-video rate comes from hoursByTopic
// instead.
export const MODULE_QUIZ_HOURS = 1
export const AI_PRACTICE_HOURS = 0.25

// video_trainings entries -> a topic -> hours lookup, the shape
// hoursByStaff() needs to tell a Video Training results row apart from a
// Module Quiz one (same results table, only topic membership here
// distinguishes them — Video Training's and Module Quiz's topic
// namespaces never collide by design).
export function videoHoursByTopic(videoTrainings) {
  const map = new Map()
  for (const v of videoTrainings) map.set(v.topic, v.hours)
  return map
}

// results rows (Video Training + Module Quiz, shared table) + aiResults
// rows (AI Practice, separate table) -> per-staff hours-this-year, both
// filtered to Timestamp falling in `year` (defaults to the current
// calendar year). A results row counts at its video's real hours if its
// Topic is a video-training topic, otherwise the flat Module Quiz rate;
// every aiResults row counts at the flat AI Practice rate, no topic check
// needed (ai_results is exclusively AI Practice). Sorted ascending by
// hours — staff furthest behind the 120hr target surface first, the
// actual point of a manager-facing view.
export function hoursByStaff(results, aiResults, hoursByTopic, year = new Date().getFullYear()) {
  const byStaff = new Map()
  function add(name, outlet, hours) {
    const key = `${name}|${outlet}`
    if (!byStaff.has(key)) byStaff.set(key, { name, outlet, hours: 0 })
    byStaff.get(key).hours += hours
  }
  for (const r of results) {
    if (new Date(r.Timestamp).getFullYear() !== year) continue
    add(r.Name, r.Outlet, hoursByTopic.has(r.Topic) ? hoursByTopic.get(r.Topic) : MODULE_QUIZ_HOURS)
  }
  for (const r of aiResults) {
    if (new Date(r.Timestamp).getFullYear() !== year) continue
    add(r.Name, r.Outlet, AI_PRACTICE_HOURS)
  }
  return [...byStaff.values()].sort((a, b) => a.hours - b.hours)
}
```
