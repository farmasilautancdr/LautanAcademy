# CPD Hours Tracking (120hr/year) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every staff member accumulates hours toward a fixed 120-hour/calendar-year target by completing Video Training videos; staff see their own progress on the Dashboard, Outlet/Area Managers and Supervisor see a per-staff breakdown on their existing Staff Results pages.

**Architecture:** One new column (`video_trainings.hours`, Supervisor-set manually per video) is the only new stored state — hours-this-year is always computed on read by joining `results` to `video_trainings` on `topic`, filtered to the current calendar year. The staff-facing single number is computed server-side (one new field on `GET /data/scoped-data`); the three manager-facing per-staff breakdowns are computed client-side via a new shared composable, `useCpdHours.js`, fed by data those pages already fetch (`GET /data/scoped-data`) plus one new fetch (`GET /video-trainings`) each already makes trivial to add.

**Tech Stack:** Same as the Video Training plan this depends on — Node.js/Express/Postgres (backend repo), Vue 3/Vue Router 4/vue-i18n (frontend repo). No new dependencies.

async function videoHoursThisYear(outlet, name) {
  const { rows } = await pool.query(
    `select coalesce(sum(vt.hours), 0) as hours
     from results r
     join video_trainings vt on vt.topic = r.topic
     where r.outlet = $1 and r.name = $2
       and extract(year from r.created_at) = extract(year from now())`,
    [outlet, name]
  );
  return Number(rows[0].hours);
}

### Task 4: Frontend — `useCpdHours.js` composable

**Files:**
- Create: `lautan-academy-frontend/src/composables/useCpdHours.js`

**Interfaces:**
- Produces: `videoHoursByTopic(videoTrainings)` — `videoTrainings: {topic, hours}[] -> Map<topic, hours>`. `hoursByStaff(results, hoursByTopic, year?)` — `results: {Topic, Name, Outlet, Timestamp}[], hoursByTopic: Map<topic, hours> -> {name, outlet, hours}[]`, sorted ascending by hours (staff furthest behind the target first). Consumed by Tasks 6, 7, 8.

- [ ] **Step 1: Create the composable**

```js
// Pure calculation, no reactive state of its own — every call site already
// owns its own `results`/`video_trainings` refs from the API calls it was
// already making. Reused identically by all three manager-facing Staff
// Results pages instead of triplicating the same join+group logic. See
// docs/superpowers/specs/2026-08-12-cpd-hours-design.md.

// video_trainings entries -> a topic -> hours lookup, the shape
// hoursByStaff() needs.
export function videoHoursByTopic(videoTrainings) {
  const map = new Map()
  for (const v of videoTrainings) map.set(v.topic, v.hours)
  return map
}

// results rows -> per-staff hours-this-year, filtered to rows whose Topic
// is a real video-training topic (hoursByTopic.has(...)) and whose
// Timestamp falls in `year` (defaults to the current calendar year).
// Sorted ascending by hours — staff furthest behind the 120hr target
// surface first, the actual point of a manager-facing view.
export function hoursByStaff(results, hoursByTopic, year = new Date().getFullYear()) {
  const byStaff = new Map()
  for (const r of results) {
    if (!hoursByTopic.has(r.Topic)) continue
    if (new Date(r.Timestamp).getFullYear() !== year) continue
    const key = `${r.Name}|${r.Outlet}`
    if (!byStaff.has(key)) byStaff.set(key, { name: r.Name, outlet: r.Outlet, hours: 0 })
    byStaff.get(key).hours += hoursByTopic.get(r.Topic)
  }
  return [...byStaff.values()].sort((a, b) => a.hours - b.hours)
}
```
